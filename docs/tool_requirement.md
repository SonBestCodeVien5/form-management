# Tool Requirement

## Required
- Node.js LTS
- npm
- Docker + Docker Compose
- VSCode
- MongoDB Compass (optional)
- REST Client extension hoặc Postman để test API

## Runtime Libraries
- express
- mongoose
- ejs
- express-session
- bcrypt
- dotenv

## Dev Libraries
- nodemon

## Ghi chú
Dự án hiện sử dụng **Session-based Authentication**.
